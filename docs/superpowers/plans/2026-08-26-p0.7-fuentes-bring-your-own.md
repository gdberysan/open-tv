# P0.7 — Fuentes (bring-your-own) · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) o superpowers:executing-plans. Pasos con checkbox (`- [ ]`).

**Goal:** las fuentes de canales pasan de un seed oculto a una funcionalidad gestionada por el usuario: instalación limpia arranca SIN fuentes, con onboarding (pegar URL M3U / subir `.m3u` / sugeridas de un toque), vista de gestión, disclaimer, facetas buscables y pie de crédito de marca — con la DB existente del autor intacta y el contrato Flutter congelado.

**Architecture:** una capa `sources` sobre la tabla `providers` existente (ALTERs idempotentes, seed retirado), `Syncer` iterando las fuentes activas de la DB (el parser M3U ya es streaming sobre un reader; gana `file://` para uploads), endpoints web-only `/sources*`, y en el cliente: onboarding/estado-sin-fuentes, vista Fuentes, buscador de facetas y footer.

**Tech Stack:** Go 1.25 + chi v5 + modernc/sqlite · Svelte 5 + TS + Vite · Vitest + testing-library. Ninguna dependencia nueva.

**Spec:** `docs/superpowers/specs/2026-08-26-p0.7-fuentes-bring-your-own-design.md` (autoridad; decisiones 1-7 cerradas).

## Cross-cutting interfaces (definidas una vez; verbatim)

**Backend:**
- Tabla `providers` gana columnas vía ALTER idempotente (patrón `tvg_id`): `label TEXT NOT NULL DEFAULT ''` y `kind TEXT NOT NULL DEFAULT 'url'` (`'url'|'file'`). `type` sigue siendo `'opensource'` para toda fuente M3U (es el parser que las lee); NO se cambia el CHECK.
- `ports.Source struct { ID, Label, URL string; Kind string; IsActive bool; UltimoSync int64; Canales int }`.
- `ports.SourceRepository interface { List(ctx) ([]Source, error); Add(ctx, s Source) error; Remove(ctx, id string) error; TouchSync(ctx, id string, cuando int64) error }` — impl en `internal/adapters/db/source_repository.go`. `Remove` borra la fila Y los canales/streams de ese provider (reutiliza el borrado por provider existente/`DeleteStale`-like). IDs de fuente: `fnv64a` de la URL (determinista, como los streams) con prefijo `src-`.
- `seedProviders` se RETIRA de `db.Open` (instalación limpia = 0 fuentes). `IPTV_ORG_URL` (env) pasa de default a **opt-in**: si está definida, `main.go` hace upsert de esa fuente (mismo INSERT ON CONFLICT DO NOTHING); documentado como atajo de dev.
- `opensource.Provider` acepta `file://<ruta>`: si `base_url` empieza por `file://`, abre el fichero (bajo `<datadir>/fuentes/` SOLO — validar el prefijo, nunca una ruta arbitraria) y pasa el mismo reader al parser streaming. Uploads se guardan como `<datadir>/fuentes/<id>.m3u`.
- `services.Syncer` pasa de un provider fijo a **iterar** `SourceRepository.List` en cada ciclo (construye un `opensource.NewProvider(id, url, client)` por fila; mismo backoff/caps) y gana `SyncOne(ctx, id) error` para re-sync puntual. `DeleteStale` sigue por provider → la fusión y el borrado por fuente ya funcionan.
- Endpoints (handler `internal/api/handlers/source_handler.go`, rutas en router.go):
  - `GET /sources` → `[{"id","label","url","kind","ultimo_sync","canales"}]`
  - `POST /sources` → JSON `{"url","label"?}` O multipart campo `fichero` (`.m3u`/`.m3u8`, `io.LimitReader` 50MB como el provider); valida esquema http/https para URL; crea fila + dispara `SyncOne`; `201` con la fuente. Errores: `400` inválida, `409` duplicada.
  - `DELETE /sources/{id}` → `204`. `POST /sources/{id}/sync` → `202`.
  - `GET /sources/sugeridas` → constante Go de **punteros** `[{"label","url"}]`: IPTV-org global (`https://iptv-org.github.io/iptv/index.m3u`), México (`.../countries/mx.m3u`), EE.UU. (`.../countries/us.m3u`), España (`.../countries/es.m3u`), Noticias (`.../categories/news.m3u`), Películas (`.../categories/movies.m3u`). Sin datos de canales.

**Cliente:**
- `CatalogSource` gana: `fuentes(): Promise<Fuente[]>`, `anadirFuente(url, label?): Promise<Fuente>`, `anadirFuenteFichero(f: File): Promise<Fuente>`, `quitarFuente(id): Promise<void>`, `resyncFuente(id): Promise<void>`, `fuentesSugeridas(): Promise<{label,url}[]>`.
- `Fuente { id: string; label: string; url: string; kind: 'url'|'file'; ultimoSync: number|null; canales: number }`.
- `Onboarding.svelte` (estado sin-fuentes en App), `Fuentes.svelte` (vista de gestión, hash `#fuentes` como PanelStats), `PieDeMarca.svelte` (footer), buscador en `BarraLateralFacetas`.
- Asset: `web/public/marca/korven-emblema.svg` (ya en el repo).

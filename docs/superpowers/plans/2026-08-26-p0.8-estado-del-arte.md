## Cross-cutting interfaces (definidas una vez; verbatim)

- **`web/src/lib/fuzzy.ts`** (Tarea 3): `export function coincideDifuso(termino: string, texto: string): number | null` — devuelve un score (mayor=mejor) si `termino` casa de forma difusa (subsecuencia, acento/caso-insensible con la normalización NFD ya usada en facetas) con `texto`, o `null` si no casa. Puro, sin estado.
- **`web/src/estado/preferencias.ts`** (Tarea 5, patrón favoritos/historial): `interface Preferencias { densidad: 'comoda'|'compacta'; recordarVista: boolean; recordarFiltros: boolean }`; `crearPreferencias(): Writable<Preferencias> & {…}` con clave `opentv.preferencias`, try/catch → default `{densidad:'comoda',recordarVista:true,recordarFiltros:false}`. Reactivo.
- **Densidad → `RejillaVirtual`** (Tarea 5): la rejilla acepta una prop `densidad` (o un `anchoMin` derivado): `comoda`→ANCHO_MIN 160 (actual), `compacta`→~128. Recalcula `columnas`/ventana sin romper el roving tabindex ni los espaciadores.
- **Vista-hash** (Tareas 4/6): `#ajustes` sigue el patrón de `#fuentes`/`#stats` en `App.svelte` (`vistaAjustes = $state(hash==='#ajustes')`, gated bajo la condición de «no otra vista/modal»). El palette NO es vista-hash: es un modal efímero con estado `$state` (abierto/cerrado), abierto por ⌘K.
- **Reproductor existente** (Tareas 1-2): ya tiene `silenciado` (`video.muted`), `requestFullscreen()` (hoy sobre el `<video>`), `alTeclado`/Escape, focus-trap (`botonCerrar`, `contenedorDialogo`), failover + CTA de mirror, PlaybackGuard. Se AMPLÍA, no se reescribe.

# P0.6 — UX «Sala de control» · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) o superpowers:executing-plans para implementar tarea a tarea. Los pasos usan checkbox (`- [ ]`).

**Goal:** rediseñar el cliente web a la dirección «Sala de control» — barra lateral de facetas con conteos, tarjetas legibles (punto de salud + latencia + resolución), «Continuar viendo» desde `localStorage`, *surf* con barra espaciadora, y los tres estados en el lenguaje Korven — reutilizando la virtualización, el failover y la a11y de P0.5, con `mobile/` intacto y el contrato Flutter congelado.

**Architecture:** reorganización de la capa de presentación Svelte 5. Shell de dos columnas (facetas + área principal) bajo una cabecera con indicador de señal honesto; la rejilla virtualizada y su a11y se reutilizan sin cambios estructurales; se añaden un módulo de historial en `localStorage` y un endpoint aditivo de facetas de calidad. Reproductor sigue modal.

**Tech Stack:** Svelte 5 (runas `$state/$derived/$props/$effect`) + TypeScript + Vite + hls.js (chunk perezoso) · Go 1.25 + chi v5 + modernc/sqlite · Vitest + @testing-library/svelte · tokens Korven embebidos.

**Spec:** `docs/superpowers/specs/2026-08-25-p0.6-ux-sala-de-control-design.md` (autoridad; 9 decisiones cerradas). Trampas del catálogo en `docs/superpowers/specs/2026-08-08-korven-open-tv-design.md`; fiabilidad reutilizada en `docs/superpowers/specs/2026-08-25-p0.5-fiabilidad-y-robustez-design.md`.

## Global Constraints

- **Idioma:** todo el código, comentarios, mensajes de commit y texto de UI en **español**. UI también en inglés: i18n ES fuente de verdad, EN es `Record<ClaveMensaje,string>`. **Toda clave nueva se añade en es Y en en**, con paridad.
- **Gates verdes al final de CADA tarea:** `gofmt -l .` (vacío) · `go vet ./...` · `go build ./...` · `go test -race -count=1 ./...`; en tareas que tocan `web/`: `cd web && npm run check && npm test && npm run build`; `cd mobile && flutter analyze && flutter test`.
- **`mobile/` no se toca.** `git diff --stat main..HEAD -- mobile/` vacío.
- **Contrato JSON Flutter intocable.** `domain.Channel` conserva 15 claves; `GET /channels`, `GET /channels/stream` con su forma exacta. Endpoints nuevos (`/channels/qualities`) son solo del cliente web, snake_case en minúsculas.
- **`domain` sin imports externos.** Solo stdlib. **Cero `_` descartando errores** en producción; `%w`; `slog`, nunca `fmt.Println`. **Ninguna dependencia Go nueva.**
- **Ninguna librería JS nueva** salvo justificación + versión exacta + tamaño gzip anotado. **Presupuesto ≤ 80 KB gzip** de JS propio inicial; `hls.js` sigue lazy; gate de bundle CI se mantiene.
- **Tokens de marca:** se **AÑADEN** tokens semánticos a `web/src/estilos/tokens/`; **nunca** se cambian valores del núcleo Korven. Cero literales de color/sombra/scrim en componentes: todo referencia un token.
- **El ámbar `#FF8A2B` significa señal viva** — directo, filtro activo, foco — y nada más. El punto de salud «viva» es pino `--signal-ok`, NO ámbar.
- **Proxy solo loopback**; `MismoOrigen` y la SSRF de P0.5 no se tocan.
- **Identidad git:** todo commit como `gdberysan@gmail.com` (¡verificar `git config user.email` ANTES de cada commit!); termina con `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- **Rama `feat/p0.6-ux-sala-de-control` desde `main`. Sin push.** Nada hace el repo público.
- **No `git add -A`.** Untracked ajenos: `docs/prompts/`, `open-tv-interface-design/`, `docs/superpowers/plans/2026-08-25-baseline-de-seguridad.md`. Cada tarea añade solo sus ficheros.
